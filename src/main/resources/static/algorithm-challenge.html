Debug the Algorithm

The program should find the largest number in an array. Find the algorithm error and correct the code. 

public class Main {

    public static void main(String[] args) {

        int[] numbers = {10, 25, 7, 42, 18};

        int largest = 0;

        for (int number : numbers) {

            if (number < largest) {
                largest = number;
            }
        }

        System.out.println("Largest: " + largest);

    }
}
